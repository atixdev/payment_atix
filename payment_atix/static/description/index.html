Guía de Instalación y Configuración del Módulo Pasarela de Pago Atix

Requisitos Previos

  • Contar con una instancia de Odoo (Community o Enterprise).
  • El sistema puede estar alojado de forma local ("on premise"), en la nube o en odoo.sh.
  • Verificar que la aplicación Proveedor de pago: ATIX esté disponible en la lista de aplicaciones del sistema.
  • Obtener las API KEY (en soles y/o dólares) desde el dashboard de Atix:
    • Accede a https://dashboard.atix.com.pe/login para generar tus credenciales.

Pasos para la Instalación

  1. Accede al menú Aplicaciones en tu instancia de Odoo.
  2. Busca e instala el módulo Proveedor de pago: ATIX.

Pasos para la Configuración

  1. Dirígete a Sitio Web -> Configuración -> Proveedores de Pago.
  2. Activa el proveedor de pago ATIX.
  3. Configura las API KEY en dólares y/o soles según corresponda:
    • El módulo funciona con una o ambas monedas configuradas.
  4. Define el estado del proveedor de pago:
    • Si las API KEY son de producción, selecciona el estado Habilitado.
    • Si las API KEY son de pruebas, selecciona el estado Modo de prueba.
  5. Copia la URL de redireccionamiento generada en Odoo y pégala en los campos correspondientes del dashboard de Atix:
    • Redirección si la transacción es aprobada
    • Redirección si la transacción es rechazada

Pruebas del Módulo

Para verificar que el módulo funciona correctamente, sigue estos pasos:

  1. Accede al flujo de compra en tu sitio web.
  2. Selecciona un producto y procede al pago.
  3. Confirma que el método de pago Atix esté disponible y seleccionado por defecto (si es el único método configurado).

Completa la transacción y verifica que se procese correctamente.

Si la transacción es exitosa, deberías ver una confirmación en pantalla. En caso de errores, revisa los logs y verifica la configuración del módulo.
